> **"社会の存続と少子化は、道徳や価値観（ポエム）ではなく、不可避な固定費を差し引いた後の「実効生存エネルギー比率（無次元スカラー）」によって決定論的に支配される。"**

**SMI Framework** は、近代都市資本主義社会における個体の可処分生存余白を定量化し、総出生率（TFR）の長期弾道および社会システムの相転移を予測するオープンソースの社会物理・計量経済プロトコルである。

---

## 1. 動作環境と適用境界条件（Operational Boundary Conditions）

本フレームワークは、無条件にあらゆる時代・共同体に適用される汎用抽象論ではなく、以下の **3大境界条件（近代都市資本主義OS）** を満たす社会システム専用の決定論的モデルである。

1. **貨幣・市場決済経済（Monetized Market Economy）：** 住居、栄養、光熱、教育、税・社会保障の主要固定費が法定通貨によって市場決済されていること（自給自足共同体や完全現物配給体制は対象外）。
2. **個体の自由意志と契約自律性（Individual Autonomy）：** 男女双方に未婚・不婚・避妊・生活様式の自律的選択権が法的に担保されていること（強制配偶制度や閉鎖的ドグマ共同体は対象外）。
3. **子どもの構造的純負債化（$P_{net} < 1.0$）：** 児童労働禁止と義務教育により、子どもが成人するまで家計の純固定費（負債）として機能する近代都市環境であること（子どもが労働力として黒字化する伝統農村は対象外）。

## 2. 基礎方程式と二重観測レンズ（Core Equation & Dual-Lens Architecture）

### 2.1 無次元基本方程式（SMI Lite Standard）

対象地域メッシュまたは集団 $i$ の時点 $t$ における **SMI (Social Margin Index)** は、通貨単位や名目インフレに依存しない無次元比率として定義される。

$$
SMI_{i, t} = \frac{WCI_{i, t}}{C_{surv\_std}(i, t)}
$$

* **分子** $WCI_{i, t}$ **(Working Capital Income)：** 若年単身層（25〜34歳）の実効可処分所得（所得税・住民税・社会保険料控除後手取り）。
* **分母** $C_{surv\_std}(i, t)$ **(Standard Survival Cost)：** 絶対固定費（適正民間家賃・基礎栄養・必須光熱インフラ）と準固定費（限界税社保・減価償却引当・通信・相対的世間体教育コスト $\theta \cdot R_{rel}$）の線形和。
  * *※ 公的総合CPIによる実質化は、耐久消費財の価格下落によって生活実感と激しく乖離するため意図的に排除している。*

### 2.2 二重観測レンズ（Standard Lens & Canary Model）

SMI Framework は、基礎方程式（カメラ本体）を一切改変せず、入力する所得分位フィルター（光学レンズ）を切り替えることで、マクロ出生率の弾道予測と、中間層崩壊に先行する構造的劣化の早期検知を両立する。

* **Standard Lens（標準レンズ / 全体中央値 $P50$）：** 25〜34歳・自力労働層（Track A）の中央値を投入。生体クロックに基づく **3〜5年の遅延分布（主ピーク4年）** と4PLロジスティック関数を経て、国・地域のTFR（出生率）弾道を予測する。
* **Canary Lens（カナリア・レンズ / 下位 $25\text{–}40\%$ 分位）：** 同世代の勤労下位〜非正規層（Track A）のデータを同一式に投入。中間層全体の崩壊に **12〜15年先行** して危険水域（$0.60$ 割れ）および物理下限への張り付きを検知する早期警戒アラートとして機能する。

## 3. 5段階の普遍相転移閾値（Universal Phase Thresholds）

算出される無次元数 $SMI$ は、国家や文化圏を問わず以下の5段階の相転移閾値によって生体・社会状態を機械的に規定する。

| SMI 領域・閾値 | ステータス名称 | 生体・社会システムの物理状態 |
| :--- | :--- | :--- |
| **$\ge 2.07$** | **人口置換水準（ブースト域）** | 出生率が人口置換水準（$\approx 2.07$）を安定的に上回り、自然増へ転じる領域。 |
| **$1.40$** | **世帯形成・再生産黄金帯** | OECD等価尺度（追加成人 $+0.5$、小児 $+0.3$）と整合する平時巡航ライン。 |
| **$1.00$** | **空荷自立限界線** | 単身個体が将来引当を含めて辛うじて収支均衡する境界線（復旧バッファーゼロ）。 |
| **$< 0.60$** | **自律停止・身食い圏** | 前頭前野の防衛ブレーキが作動し、減価償却・将来資産を食いつぶしながら繁殖を停止する領域。 |
| **$\approx 0.45$** | **労働市場の床（フロア定数）** | 制度や福祉水準が真逆の先進諸国（日・米・スウェーデン・伊・ハンガリー等）すべてで観測される、自力労働市場（Track A）に留まれる物理的絶対下限（$0.44 \sim 0.53$）。これ以下への圧迫は公的扶助依存（Track B）または地下経済・治安崩壊（$\text{Toxicity}$）への強制相転移を引き起こす。 |

## 4. 実証ベンチマークと国際比較ハイライト

* **日本（戦後〜現代バックテスト）：** 1990年以前の構造データのみでキャリブレーションしたSMI曲線は、その後の30年間（1991〜2020年）のTFR低下軌道を $R^2 > 0.81$（4年遅延ピーク）で正確に捕捉する。
* **先進4カ国クロス検証（米・スウェーデン・イタリア・ハンガリー）：** 税制・家族手当・福祉モデルが正反対の4カ国すべてにおいて、自力労働層（Track A）のカナリア層（下位25〜40%）が **$0.44 \sim 0.53$ の「労働市場の床」** に収斂することを確認。さらにカナリア層の $0.60$ 割れ時期は、各国のマクロ社会摩擦（治安悪化・薬物危機・社会分断）の爆発時期と時間軸上で一致する。

## 7. 第2階層アーキテクチャ：SMI Core Kernel（安全保障・空間摩擦エンジン）

本公開リポジトリで提供される第1階層（SMI Lite）は、個体の可処分エネルギー余白と人口動態の弾道を追跡するオープン標準である。

しかし、国家および都市システムのマクロな存続は、単なる家計収支だけでなく、**「局所空間密度（$D_{local}$）」「文化・法規範距離（$H_{dist}$）」**、およびそれらが臨界点を超えた際に爆発する **「非線形社会摩擦（$\text{Toxicity}$）」** によって不可逆的な相転移（実質的自治区化・行政権失効）を引き起こす。

SMI Framework では、これらの空間安全保障・国家統治エンジンを **第2階層（SMI Core Kernel）** として隔離された環境で管理している：

* **非線形摩擦関数 $\text{Toxicity}(t)$：** $1\text{km} \times 1\text{km}$ メッシュ単位の行政・治安飽和コストと、カナリア層崩壊（$SMI_{canary} < 0.60 \to 0.45$）との結合トリガーを算定。
* **空間相分離および不可逆点（PoR）判定アルゴリズム：** シェリング分断モデルを拡張し、標準統治が機能不全に陥る数学的臨界点（Phase 1〜3 / PoR）を特定。
* **20年世代交代・国家第1崩壊線予測：** 1世流入から20年後（2世の成人スパイク）と国内防衛・インフラ維持人員の物理的欠損が交差する弾道を予測。

### 🔒 第2階層（Core Specifications）へのアクセス申請について

悪意ある政治的利用やイデオロギー的ノイズを排除し、厳格な工学的検証環境を維持するため、完全版仕様書（`SPECIFICATION_CORE.md`）および非公開R&D Issueトラッカーはプライベートリポジトリに隔離されている。アクセスは身元が確認された研究機関、政策アナリスト、防衛・安全保障関係者、および適格なシステムアーキテクトに限定して許可される。
