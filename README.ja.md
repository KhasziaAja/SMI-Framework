# SMI Framework (Social Margin Index) - v1.0 [Open Standard]

[English](./README.md) | [日本語](./README.ja.md)

> **"社会の存続と崩壊は、道徳や意識変化（ポエム）ではなく、個体の可処分生存エネルギー（物理量）で決定される。"**

SMI Framework は、高度資本主義社会における少子化、未婚化、人口急減、および社会システムの機能不全メカニズムを、感情論を排した「エネルギー収支」として定量化・予測・シミュレーションするためのオープンソース・社会工学標準プロトコル（State OS基幹アーキテクチャ）である。

---

## 1. 宣言と適用境界条件（System Philosophy & Boundary Conditions）

### 1.1 宣言：生体防衛ブレーキの解除
現代の先進国および都市化社会において、少子化や婚姻率低下は「若者の草食化」「価値観の多様化」「子育て支援の不足」といった情緒的解釈（言語的ポエム）によって議論されてきた。しかし、対症療法的な給付金や啓発キャンペーンを投下しても、出生動態の急落は停止していない。

人間という生物（大型哺乳類・K戦略種）において、生殖・長期投資・世帯形成は、個体の生存基盤が脅かされた際に前頭前野および自律神経系（HPA軸）が作動させる**「生体防衛ブレーキ（Autonomic Shutdown：自律停止）」**によって物理的に遮断される。

本プロトコルは、特定の政治思想や道徳観を強制するものではない。通貨や物価水準に依存しない**無次元の物理メーター（バイタルモニター）**を社会工学に導入し、国家・自治体・組織の構造的デバッグを実行するための共通言語を提供する。

### 1.2 動作環境を定義する3大適用境界条件
本モデルは、無条件にあらゆる社会・文明で動作する抽象論ではなく、以下の3大条件を満たす「近代都市資本主義社会」を前提動作環境（OS）として規定する。

1. **貨幣・市場決済経済（Monetized Society）：** 生存・再生産に必要な固定費の大半が市場を介し法定通貨で決済されていること（自給自足農村や配給制共産圏は対象外）。
2. **個体の自由意志と契約自律性（Individual Autonomy）：** 未婚・不婚・避妊・生活様式の選択権が個体に担保されていること（奴隷制や宗教的強制生殖コミュニティは対象外）。
3. **子どもの構造的純負債化（Child Net Cost / $P_{net} < 1.0$）：** 児童労働の禁止と義務教育により、子どもが成人まで一方的な消費主体（固定費）であること（子どもが5歳から労働力として分子に貢献する伝統的農村は対象外）。

## 2. 基礎方程式（1階モデル：SMI Lite）

個体（若年単身層）の獲得可能エネルギーと、社会が要求する不可避の生存維持コストの比率を **SMI (Social Margin Index)** と定義する。

$$SMI = \frac{WCI}{C_{surv\_std}} = \frac{WCI}{C_{base} + C_{semi}}$$

### 変数定義（Variables）

* **$WCI$ (Working Capital Income：実効可処分所得中央値)**  
  対象地域における若年単身層（25〜34歳）の、税・社会保険料を控除した実効手取り中央値。
* **$C_{surv\_std}$ (標準生存維持費用：Standard Survival Cost)**  
  公的扶助（生活保護）水準ではなく、個体が心身の健康と適正な自立・社会参加を維持するための標準固定費。
  $$C_{base} = C_{rent} + C_{food\_min} + C_{infra\_vital}$$
  $$C_{semi} = C_{tax\_ins} + C_{depr} + C_{conn} + (\theta \cdot R_{rel})$$
  * $C_{rent}$: 民間適正家賃（単身25〜30㎡水準の中央値）
  * $C_{food\_min}$: 基礎栄養維持費（自炊ベースの必須カロリー支出）
  * $C_{infra\_vital}$: 生存必須光熱水道費
  * $C_{tax\_ins}$: 限界的な税・社会保険料負担実効額
  * $C_{depr}$: 自衛減価償却引当（敷金更新料、家電更新、予防医療、冠婚葬祭積立）
  * $C_{conn}$: 就業・社会維持に不可欠な通信インフラ費
  * $\theta \cdot R_{rel}$: 相対的標準コスト項（周囲の教育投資競争・世間体摩擦）

> **注記（公的CPIによる実質化の排除）：**  
> 本モデルにおける分母（$C_{surv\_std}$）は、公的総合CPIによるデフレートを意図的に排除している。耐久消費財の低価格化で希釈される公的CPIではなく、生体OSが直接感知する「回避不能な4大固定費（都市適正家賃・税社保限界負担・必須インフラ・予防医療教育引当）」に限定した実物バスケット（生体生存固定費）として直接算定・評価する。

## 3. 4大相転移閾値（Phase Transition Thresholds）

SMIは通貨単位を相殺した無次元数（純粋倍率）であり、時代や為替、国境を超えて以下の物理境界線（相転移点）として機能する。

```text
   SMI スコア       システム状態                   生体・社会の挙動
───────────────────────────────────────────────────────────────────────────────────────────────
   < 0.60           Mode 0: 自律停止・身食い圏     前頭前野の認知帯域枯渇（慢性的赤字）
                                                   極度の繁殖遮断。TFRは0.6〜0.9へ急落。
                                                   若年層は将来の健康・資本を削り延命する。
───────────────────────────────────────────────────────────────────────────────────────────────
   1.00             Mode 1: 空荷自立・防衛限界線   バッファーゼロの単身自立ライン
                                                   個体維持は可能だが他者を背負う余白は皆無。
                                                   婚姻は停止し、ペア形成は生存の危機となる。
───────────────────────────────────────────────────────────────────────────────────────────────
   1.40             Mode 2: 再生産黄金帯           生物学的ペア形成・世帯形成バッファー
                                                   OECD等価尺度（+40%の余剰空間）と完全一致。
                                                   前頭前野の防衛ブレーキが解除され自然成婚。
───────────────────────────────────────────────────────────────────────────────────────────────
   ≥ 2.07           Mode 3: 人口置換・拡張域       人口置換水準（TFR 2.07〜2.15）達成領域
                                                   外部補充なしで自律的に文明が再生産される。
                                                   有事のトラウマを解除する過充電モード。
───────────────────────────────────────────────────────────────────────────────────────────────
```

## 4. 伝達関数と時間軸ダイナミクス

### ① TFR応答（4パラメータ・ロジスティック関数）
SMIの向上に対する出生率（TFR）の応答は、線形（直線）ではなく上限飽和を伴うS字シグモイド曲線（4PL）を描く。

$$TFR(SMI) = TFR_{min} + \frac{TFR_{max} - TFR_{min}}{1 + \left(\frac{SMI}{SMI_0}\right)^{-k}}$$

* $SMI_0 \approx 1.05$（変曲点：繁殖ロックの解除開始ライン）
* $k \approx 4.0$（Hill係数に相当する急峻度パラメータ）
* $TFR_{min} \approx 0.65$（極限環境における生物学的フロア値）
* $TFR_{max} \approx 2.15$（都市型社会の制度的・生体収容力天井）

### ② 時系列遅延分布（Distributed Lag Model）
人間（K戦略大型哺乳類）の生命史制約に基づき、環境好転（SMI上昇）から初産（TFR上昇）までのシステムレイテンシは、成体寿命の約5%（$t+3 \sim 5$ 年、主ピーク4年）の遅延分布として表れる。

$$TFR_t = \sum_{\tau=3}^{5} w_\tau \cdot TFR\Big(SMI(t - \tau)\Big) \quad (w_3 = 0.20, \ w_4 = 0.65, \ w_5 = 0.15)$$

```text
t = 0 年       t + 1 年       t + 2 年       t + 3 年       t + 4 年 (主ピーク)
───┼──────────────┼──────────────┼──────────────┼──────────────┼──────────────▶
 ［SMI改善］   ［認知警戒解除］ ［配偶探索開始］ ［世帯形成・受胎］ ［初産・TFR反転］
 (政策介入)     (前頭前野安静)   (交際インフラ)   (婚姻手続き)   (マクロ統計顕在化)
```

## 7. 構造的拡張：2階（Core Kernel）プロトコルについて

本公開リポジトリで提供しているSMIモデル（1階）は、個人の経済的余剰と繁殖動態を制御する「基盤OS」である。

しかし、実際の国家・地域動態においては、単なる経済コストだけでなく、
**「空間的集積度」「文化・法規範距離」「社会的摩擦コスト（Toxicity）」**
が内生変数として作用し、特定の相転移（Phase Transition / 自治区化）を引き起こす。

当プロジェクトでは、1階のSMIに対し、以下の要素を統合した**「Core Kernel（2階プロトコル）」**を別途定義・保持している。

       │       - 4PL シグモイド応答 ＆ 寿命5%ラグ（t+4）標準時間軸   │
       │       - データ交換スキーマ（SMI-OpenAPI / JSON Schema）       │

### 2階 Core エンジンの主要機能
* **非線形空間摩擦関数 $\text{Toxicity}(m, t)$ の完全展開式:** 局所集積度（$D_{local}$）、規範距離（$H_{dist}$）、空間クラスタ度（$C_{cluster}$）による限界行政コストの爆発モデル。
* **空間相分離・自治区化判定アルゴリズム（Phase 1〜3 / Point of No Return）:** 警察権および主権行政権の不可逆な失効判定。
* **20年第一崩壊線・世代交代弾道予測モデル:** 防衛・警察・基幹インフラ要員の不可逆的欠落シミュレーション。
