## 1. 科学的反証可能性基準（Falsifiability & Model Rejection Protocol）

学術的・工学的な誠実性を担保し、疑似科学や主観的ドグマ（ポエム）への退行を完全に排除するため、SMI Framework は以下の「モデル破棄条件（Falsifiability Criteria）」をあらかじめ宣言する。

### 1.1 適用境界条件（Operational Preconditions）

本反証プロトコルは、以下の3大条件を満たす「近代都市資本主義OS」環境下においてのみ有効に機能する。

1. **貨幣・市場決済経済：** 生存維持費用の大半が法定通貨で市場決済されていること（自給自足農村や配給制共産圏は対象外）。
2. **個体の自由意志：** 婚姻・避妊・生活様式の自律的選択権が担保されていること（強制配偶や宗教的絶対多産共同体は対象外）。
3. **子どもの構造的純負債化（$P_{net} < 1.0$）：** 児童労働禁止と義務教育により、子どもが成人まで一方的な消費主体（固定費）であること。

### 1.2 モデル棄却の境界条件（Null Hypothesis / 帰無仮説）

上記前提環境下において、以下の事象が実証された場合、本フレームワークの基本仮説は反証されたとみなし、モデルを全面的に破棄または抜本改変する。

1. **実効SMI 2.00以上の10年間担保に対する無反応:**  
   特定の国家または自治体規模の集団において、若年単身層（25〜34歳）の実効SMIを公的介入（分母切除および可処分所得底上げ）によって $SMI \ge 2.00$（有事ブースト域）へ引き上げ、その水準を10年連続で維持したにもかかわらず、介入開始から4〜6年後以降の合計特殊出生率（TFR）に統計的に有意（$p < 0.05$）な上昇トレンドが一度も観測されなかった場合。
2. **時系列因果の逆転:**  
   グランジャー因果性検定（Granger Causality Test）において、マクロな出生動態の変化が $SMI$ 変動に対して有意に先行（$TFR_t \to SMI_{t+k}$）し、かつ $SMI_{t-k} \to TFR_t$ の因果性が棄却された場合。
3. **分母無効化空間における自律停止の継続:**  
   住宅費、医療費、教育費、税・社会保険料が完全公的保障（分母ゼロ化）され、かつ可処分時間が確保されている環境下において、認知帯域の解放（HPA軸の安静化）が確認されているにもかかわらず、集団の婚姻・再生産意向が回復しない場合。

## 2. 標準検証ベンチマークデータセット（Standard Datasets）

本モデルの追試・バックテストを実施する研究者向けに、以下の公的統計データベースを標準検証セット（機械学習における MNIST に相当するリファレンスデータ）として指定する。

### 2.2 計量検定プロトコル

1. **差分系列および定常性の確認:**  
   原系列の単位根検定（ADF検定）を実施し、非定常性が確認された場合は階差系列（$\Delta SMI_t, \Delta TFR_t$）へ変換して見せかけの相関（Spurious Correlation）を排除すること。
2. **相互相関関数（CCF）の検証:**  
   $SMI_{t-k}$ と $TFR_t$ の相互相関を $k = 0 \dots 10$ の範囲で算出し、有限インパルス応答（FIR: $w_3=0.20, w_4=0.65, w_5=0.15$）に基づくピークが $k = 3 \sim 5$（主ピーク $4.0$ 年）に位置することを検証すること。

## 3. オープンIssueマスターリスト（公開プロトコル検証用）

世界中の研究者、アナリスト、エンジニアが自らの専門ツールを適用して参画できるよう、公開レイヤー（1階）における未解決課題を3大カテゴリに整理・公開する。

### ■ Category A: 計量経済・統計パイプライン系 (Econometrics & Data Pipelines)

* [ ] **Issue #01: 公的統計からのWCI・標準生存維持費用（$C_{surv\_std}$）自動抽出パイプライン（ETL）構築**  
  * **現状・課題:** 基礎式 $SMI = \frac{WCI}{C_{surv\_std}}$ は確定しているが、国・地域によって統計体系（SNA、家計調査、CPS、OECD）の勘定科目定義が異なる。
  * **検証・やること:** 日本（e-Stat）、米国（CPS/BLS）、OECDから、若年単身可処分所得中央値（$WCI$）と標準生存固定費（民間適正家賃＋税社保限界負担＋予防医療）を一発で抽出・無次元化するオープンソースの Python/R スクリプトを作成・共有すること。
* [ ] **Issue #02: 相対比較コスト項（$\theta \cdot R_{rel}$）の客観的算出アルゴリズムの固定**  
  * **現状・課題:** 先進国特有の「周囲との世間体・教育過熱・マウンティングコスト」を恣意的なフィッティングにせず、客観データから導く必要がある。
  * **検証・やること:** 地域別大学進学率、私立校比率、学習塾支出中央値、ジニ係数等から、分母加算係数 $\theta \cdot R_{rel}$ を決定論的に算出する計算仕様を確定すること。
* [ ] **Issue #03: 共働き世帯における「時間喪失・キャリア中断ストレス補正」の実数値化**  
  * **現状・課題:** 夫婦合算手取りを単純代入すると「1.5馬力トラップ（自由時間消滅・外部委託費増）」を見落とし、SMIが過大評価される。
  * **検証・やること:** 世帯労働時間データおよび家事・育児外部委託費用に基づき、分子補正 $WCI_{eff} = \frac{WCI_1 + WCI_2}{1 + \lambda \Delta H}$ のパラメータ適正レンジを策定すること。
* [ ] **Issue #04: 国際正規化プラグイン（北欧現物給付 $S_{gov}$ / 米国階層分離）のデータマッピング**  
  * **現状・課題:** 高福祉国（北欧・仏）の現物給付や事実婚（$\phi$）、米国の民間医療保険・学生ローンをコア式へどう落とし込むか。
  * **検証・やること:** 北欧の公的肩代わり率（$S_{gov}$）控除式、米国の所得五分位（Quintile）別クラスタ分離アルゴリズムを実装し、実証検証を行うこと。

### ■ Category B: 生物学・時間軸動態系 (Biology & Temporal Dynamics)

* [ ] **Issue #05: 3〜5年遅延分布（Distributed Lag）とCCFピークの統計的確定**  
  * **現状・課題:** 過去データにおいて「SMI変動から何年後にTFR（出生率）が最も強く反応するか」の分布幅の統計的証明。
  * **検証・やること:** 日本・G7・OECD諸国の過去50年分の時系列データに対し、相互相関関数（CCF）およびグランジャー因果性テストを回し、ラグ中央値（$k \approx 4.0$年前後）のピーク分布ウェイト（$w_3, w_4, w_5$）を確定すること。
* [ ] **Issue #06: 寿命換算比率（初産ラグ5% vs 生活史不変量10%）の文献メタ解析**  
  * **現状・課題:** 「環境好転から初産までの生体ロード時間（成体寿命の約5%）」と「生活史不変量（Charnov無次元数 約10%）」の生物学的定義の棲み分け。
  * **検証・やること:** K戦略大型哺乳類（12種以上）の実日数／寿命比率データを集約し、分布の山が人間換算3〜5年（平均4年）に収斂することを文献ベースで整理・引用可能にすること。
* [ ] **Issue #07: TFR 4PLロジスティック（S字飽和）関数のパラメータキャリブレーション**  
  * **現状・課題:** $SMI \ge 2.07$ 超過時における飽和現象（リッチマンの少子化パラドックス）のカーブ傾き $k$ と上限飽和値 $TFR_{max}$ の推定。
  * **検証・やること:** 確定式 $TFR(SMI) = TFR_{min} + \frac{TFR_{max} - TFR_{min}}{1 + \left(\frac{SMI}{SMI_0}\right)^{-k}}$ に対し、高SMI帯域の実測データを用いて変曲点 $SMI_0 \approx 1.05$、傾き $k \approx 4.0$ を精密フィッティングすること。
* [ ] **Issue #08: 地球規模少子化ドミノと「他国補充モデル限界点（PoE）」の推計**  
  * **現状・課題:** 途上国・新興国の都市化に伴い、子どもが生産手段（分子）から純コスト（分母）へ寝返る現象（$P_{net} < 1.0$）が世界中で加速している。
  * **検証・やること:** 主要送り出し国（ベトナム、タイ、インド、中南米等）の都市化率とTFR急落曲線をプロットし、「先進国間で若年労働力の奪い合いが起き、移民供給プールが実質消滅するデッドライン（Point of Exhaustion）」の年次を推計すること。

### ■ Category C: 制度設計・社会実装系 (Policy Engineering & Implementation)

* [ ] **Issue #09: ライフサイクル段階課税（50代回収期）における法制度・税制整合性の検証**  
  * **現状・課題:** 子育て期（20〜30代）の分母消去（減免）と、養育固定費が消滅した50代以降での回収を現行税制・社会保障にどう接合するか。
  * **検証・やること:** 扶養控除・給付付き税額控除（EITC）の再編案および、財政中立（ビルトインスタビライザー）を担保する自動循環アルゴリズムを策定すること。
* [ ] **Issue #10: 法人による「借り上げ社宅化（住宅コスト損金算入）」の国別互換性調査**  
  * **現状・課題:** 給与ではなく福利厚生費（損金）で住宅費を消すハックが、海外（米・英・独・仏）の税法でも適法に機能するか。
  * **検証・やること:** 米国のCorporate Housing、フランスのAPL、ドイツの家賃ブレーキ等の既存税制・住宅補助制度との相互運用性を検証すること。
* [ ] **Issue #11: 公的扶助と勤労中間層における「実効SMI逆転バグ」の是正キャップ設計**  
  * **現状・課題:** 勤労中間層のSMIが0.58に沈む一方、家賃・医療・教育が全額公的肩代わりされる生活保護層の実効SMIが1.5前後に浮上する「逆転現象」が勤労意欲と婚姻を破壊している。
  * **検証・やること:** 「最低賃金フルタイム勤労者の実効SMI」を下回らないよう、公的扶助の総価値に数理的上限（SMIキャップ）を連動させる政策アルゴリズムを策定すること。

## 4. 貢献ガイドライン（How to Contribute）

1. **Issue の選択:**  
   関心のある Issue 番号を指定し、リポジトリの Discussions または Issues にて検証アプローチや作業開始を宣言してください。
2. **プルリクエスト（PR）の要件:**  
   * 再現可能な分析コード（Python / R / Jupyter Notebook）を添付すること。
   * 使用した公的統計の出典およびデータ取得日を明記すること。
   * 感情的な形容詞（定性ポエム）を含めず、統計量（$p$ 値、$R^2$、AIC/BIC）で結果を記述すること。
